How to Read This Guide

Each field has a name (what it's called internally), a type (what kind of value it holds), and a description (what it means and example values). Fields marked required must always have a value. Everything else is optional — blank means we don't know yet.

Text Any words or sentence
Number A numeric value
Yes/No A true or false flag
List Multiple values
Choice Must be one of the allowed values
Section A nested group of fields
🗂

Document Structure

How all the sections fit together into one school record

📄 SchoolData (one record per school)
├─ school_name, nces_id, schema_version, last_updated
└─ intelligence (all collected details)
├─ Identity, Contact, Grades, Enrollment, Tuition, Schedule
├─ Programs, Admissions, Activities, Facilities
├─ 🔴 sped (school-wide special education)
└─ by_grade_band → by_grade (drill-down levels)
├─ grade_level_attributes (one block per grade band)
└─ sped (SPED info for that specific band)
└─ college_outcomes, school_features, evidence
Key idea: SPED data appears at three levels — school-wide, per grade band (e.g. K–2), and per individual grade (e.g. Kindergarten). Fill in as much as you can find. The structure accepts partial data at any level.

Special Education (SPED) — Priority Section

The most important section. Captures everything about how the school supports students with disabilities and learning differences.

Why three levels? A school might handle dyslexia very differently in Kindergarten vs. 8th grade. We capture SPED data at the school-wide level first, then drill down to grade bands (K–2, 3–5, etc.), then to individual grades if the detail is available.
Level 1
School-Wide SPED — Applies to the whole school. Always fill this in first.
Level 2
Grade Band SPED — Specific to a band like "K–2" or "High School". Fill in when detail differs by band.
Level 3
Individual Grade SPED — Specific to one grade, e.g. Kindergarten only. Fill in when the finest detail is available.
School-Wide SPED Fields
Field Name
Type
Description
sped_available
Yes/No
Does the school offer any special education services at all?

Yes/No
Does the school explicitly support students with learning differences (dyslexia, ADHD, etc.)?
iep_504_status
Choice
Which legal support plans does the school honor? Allowed values: iep_available, section_504_available, both_available, iep_only, not_available, unknown. (IEP = Individualized Education Program; 504 = accommodation plan under Section 504 of the Rehabilitation Act)
inclusion_philosophy
Choice
How does the school approach including SPED students in regular classes? full_inclusion = always in general ed, supported_inclusion = mostly in general ed with support, modified_inclusion = some time in general ed, separate_program = dedicated SPED classrooms, case_by_case, unknown
disability_categories_served
List
Which types of disabilities does the school serve? See full list in the Reference section below. Examples: autism, dyslexia, adhd, speech_language_impairment, developmental_delay
service_models
List

List

Evidence & Sources

How confident are we in each piece of data, and where did it come from?

Every major section carries its own evidence block. This means we know exactly which source supports which claim — not just that "we scraped it from somewhere."
Field Name
Type
Description
confidence_scores
Section
A score from 0.0 to 1.0 for each field indicating how confident we are in the value. Example: {"sped_available": 0.95, "tuition_min": 0.7}. 1.0 = fully confirmed from a primary source. 0.5 = inferred or found on a secondary site.
source_evidence
Section
The verbatim text from the source that supports each field's value. Example: {"sped_available": "We proudly offer IEP and 504 support services for all qualifying students."}
sources
List
All URLs used to compile this section. Each entry has: title (page name), url (web address), snippet (relevant excerpt), scraped_at (when it was scraped), confidence (0.0–1.0 quality score).
